# 【Suno用】WAV音源マスタリング前仕上げツール

Sunoで生成したWAV音源を解析し、曲頭のプツッ音、不要な超低域、低中域の濁り、中高域の刺さり、高域のチリつき・シュワシュワ感、再生成区間の音質差などを確認・修正するためのツールです。元のパンや空間表現をできるだけ残しながら、マスタリング前の状態に整えます。

> **原音を優先。** 問題を検出して修正案を示し、修正前後を試聴してから、使う修正だけを選べます。

## 主な機能

- 曲頭・曲末のプツッ音や不要ノイズの検出
- プツッ・パチッ音（Click / Pop）の検出と修正候補
- 音割れ・ピーク異常の確認
- 波形の中心ズレ（DC Offset）の確認・補正
- 不要な超低域の整理
- 低中域の濁りの確認・軽減
- 中高域の刺さりの確認・軽減
- 高域のチリつき・シュワシュワ感の確認・軽減
- 打楽器などの瞬間的な高域の刺さりの確認
- 左右・位相の急な変化の確認
- 音質の変化点の検出
- Suno Open Editor等で再生成した区間の音質差チェック
- 修正前 / 修正後プレビュー
- 選んだ修正だけを一度に適用
- 修正後チェック
- WAV書き出し

## 使い方

### GitHub Pages版

公開URLをブラウザで開き、Sunoから書き出したWAVをドラッグ＆ドロップするか「WAVを選択」を押してください。

### PCで直接使う場合

1. このリポジトリをZIPでダウンロードします。
2. ZIPを展開します。
3. `index.html` をChromeまたはEdgeで開きます。
4. WAVを読み込みます。
5. 自動解析が終わったら、修正候補を確認します。
6. 「修正前」「修正後を試聴」で聴き比べます。
7. 必要なものだけ「この修正を使う」を選びます。
8. 「WAVを修正する」を押します。
9. 修正後チェックが終わったら「修正版WAVを保存」を押します。

## 再生成した区間の確認

SunoのOpen Editorなどで発音修正のために一部分を再生成すると、その区間だけ音量や音質が変わる場合があります。

波形画面の「再生成区間を指定」を押し、該当箇所をドラッグすると、前後との差を解析して修正候補を表示します。

## 原則として変更しないもの

このツールはマスタリングツールではありません。以下は原則として自動変更しません。

- パンニング
- ステレオ幅
- リバーブや空間表現
- ダイナミクス
- LUFS / 全体音圧

最終的なマスタリングはLANDRなどのマスタリングサービスやDAWで行うことを想定しています。

## プライバシー

WAVの解析・修正・書き出しはブラウザ内で行います。音源ファイルをこのツールのサーバーへアップロードする処理はありません。

## 注意事項

- 現在は開発中のバージョンです。必ず元のWAVを残したまま使用してください。
- 自動検出は「問題の可能性がある箇所」を示すもので、すべてが実際の不具合とは限りません。修正前後を試聴して判断してください。
- ブラウザや端末によって処理速度が異なります。
- SunoおよびLANDRの公式ツールではありません。各サービス運営会社とは関係のない非公式ツールです。

## 動作環境

Chrome / Edgeなど、Web Audio APIに対応した比較的新しいデスクトップブラウザを推奨します。
